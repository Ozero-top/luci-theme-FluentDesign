# Login backgrounds

Drop image or video files into this directory:

- Images: `.jpg` `.jpeg` `.png` `.gif` `.webp`
- Videos: `.mp4` `.webm`

On the login page the theme picks one file at random on every visit. When the
directory is empty, the built-in Fluent gradient (`../img/login-bg.svg`) is
used. Subdirectories are ignored, and this README is ignored.

Runtime location:

```
/www/luci-static/fluentdesign/background/
```
